### **Pregunta 1 — Detección de drift entre periodos (KS test + reporte)**
**El Problema:**  
Tienes dos DataFrames de variables numéricas: uno histórico (`df_base`) y otro reciente (`df_nuevo`). Quieres detectar si cambió la distribución de las variables (data drift) para decidir si reentrenar el modelo.

**Tu Misión:**  
Escribe una función llamada `detectar_drift_ks(df_base, df_nuevo, columnas, alpha=0.05)` que:

1. Reciba dos DataFrames (`df_base`, `df_nuevo`) y una lista de columnas numéricas `columnas`.
2. Para cada columna, elimine NaN en ambos periodos.
3. Aplique la prueba **Kolmogorov-Smirnov de 2 muestras** (`sklearn`/`scipy-like approach via sklearn-compatible workflow`, si usas scipy puedes reemplazar por KS manual aproximada con numpy; preferible test estadístico estándar).
4. Genere un DataFrame con columnas:
   - `columna`
   - `ks_stat`
   - `p_value`
   - `hay_drift` (True si `p_value < alpha`)
5. Ordene por `ks_stat` de mayor a menor.
6. Devuelva:
   - el DataFrame de resultados
   - una lista con las columnas donde `hay_drift=True`.
